🪞 Mirror

Mirror is not a productivity tool.
It’s not a journal.
It’s not here to motivate you.

It shows you what you already know —
but keep avoiding.

---

⚡ What it does

Mirror asks you a few direct questions and then:

- Detects your behavioral patterns
- Compares them with who you say you want to be
- Exposes contradictions
- Tracks repetition over time
- Forces a realization instead of giving advice

---

🧠 Core Idea

«You don’t struggle because you don’t know.
You struggle because you don’t act on what you know.»

Mirror makes that visible.

---

🔥 Features

- Identity Tracking
  Understand the gap between intention and action

- Pattern Detection
  Avoidance, approval-seeking, overthinking, comfort loops

- Contradiction Engine
  Calls out when your behavior doesn’t match your goals

- Memory System
  Tracks repeated patterns across sessions

- Escalation Logic
  Gets sharper when you repeat the same mistakes

- “Too Late” Effect
  Shows the cost of delay and inaction

- Release Step
  Say what you didn’t say

---

🧪 How to Use

1. Open the app
2. Answer honestly
3. Don’t rush
4. Read the output fully
5. Do something with it

If you lie, it won’t work.
If you avoid, it will show you that too.

---

🛠 Tech

- Single HTML file
- Vanilla JavaScript
- LocalStorage (no backend)

---

⚠️ Disclaimer

This is not therapy.
This is not mental health support.

It’s a self-reflection tool designed to surface behavioral patterns.
